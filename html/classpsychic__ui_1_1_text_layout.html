Detailed Description

Lays out text with SkParagraph: shaping, font fallback, line breaking and alignment, and the geometry editing needs (caret rectangles and hit testing; TextEditing has the rest). Every index is in UTF-16 code units, like icu::UnicodeString's.

Every line is lineHeight tall, its glyphs centred in it (CSS's half-leading). One-line layouts never wrap: their text overflows the width instead, or ends in an ellipsis that fits (TextOverflow::Ellipsis), and line returns lay out as spaces.

Colors are given when painting, so a color change (a transition) never builds or lays out the paragraph again.
