Detailed Description

template<class... T>
struct psychic_ui::detail::SignalCore< T >

What a Signal shares with its slots and with its running emissions. Slots only hold a weak_ptr to it, so disconnecting after the signal died is a no-op. An emission holds a shared_ptr to it, so the slots it iterates outlive a handler that destroys the signal.
