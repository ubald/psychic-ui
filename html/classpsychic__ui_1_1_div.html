Detailed Description

The Div class is the main object used to display content in Psychic UI. It has a similar role as a div in html: its purpose is to offer a rectangular container than can be used in a layout and styled using a stylesheet.

◆ layoutOffsetX()

float psychic_ui::Div::layoutOffsetX ( ) const

Where it is painted from where its layout puts it, as it slides there: a layout transition, its parent's layoutTransition (FLIP). After a layout that moved it in the window, scrolling aside, it is painted from where it was (from where it was painted, when it was sliding already) and the offset goes to 0 with that timing; Yoga runs once. Composed with its translateX/translateY, painting only (hit testing finds it at its layout place). Nothing slides on its first layout in that container (an added child appears in place, and so does one shown again), on a window resize, with new rules (a theme, a density, a skin set) or with reduced motion. Its size doesn't animate.

◆ layoutSliding()

bool psychic_ui::Div::layoutSliding ( ) const

Whether it slides to its layout place (layoutOffsetX/Y aren't 0). It has the sliding class meanwhile (styled before the paint that starts it; its rules should only paint, a row's opaque background), and is painted after its siblings that don't slide.
