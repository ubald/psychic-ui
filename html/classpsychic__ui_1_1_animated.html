Detailed Description

template<Interpolable T>
class psychic_ui::Animated< T >

A value that moves to its targets with a timing instead of jumping, for what a component draws itself (style properties have transition). Keep it as a member of the div it belongs to: 

Animated<float> _offset{this, 0.0f, Timing{200ms, Ease::Out}};

_offset.to(row.y());         // From where it is now
float y = _offset.value();   // In draw()

Its owner's window advances it every frame (Window::updateAnimations) and draws while it moves. It jumps when its owner isn't in a window, or the window reduces motion. It ends with its owner, the window only holds it weakly.
