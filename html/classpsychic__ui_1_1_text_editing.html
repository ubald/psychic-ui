Detailed Description

The editing model of a text: the text itself, an anchor and a caret (the selection is what lies between them), the column that line moves keep, and what keys, typing and the mouse do to them. No Div: what shows the text answers the geometry questions (TextGeometry), and the clipboard is given (Clipboard).

Every index is in UTF-16 code units, like icu::UnicodeString's, and moves step over whole grapheme clusters (an emoji, a letter and its combining marks). Nothing is emitted: every operation returns what it changed (Edit), so that what owns the model tells the world once its own state is consistent.

Read-only text refuses edits but keeps the selection, the caret's moves and copying.
