Detailed Description

Shows a Psychic UI Window in an SDL3 window that has an OpenGL context.

SDL3Application makes one for each window it opens. A host application with its own SDL window, GL context and loop embeds Psychic UI the same way: 

auto ui = std::make_shared<MyWindow>();
psychic_ui::SDL3SystemWindow adapter(ui, sdlWindow, glContext);

while (running) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        adapter.handleEvent(event); // false when the event isn't for this window
    }
    adapter.render();               // makes the context current and draws
    SDL_GL_SwapWindow(sdlWindow);
}

A host that waits for events while nothing changes asks the window when to draw again (Window::untilNextFrame), as SDL3Application::run does.

For custom title bars (Window::addDragArea) and the resize borders of an undecorated window, also call adapter.installHitTest(), which replaces the window's SDL hit test.

The adapter never creates, shows, destroys or polls anything of the host's: destroy it before the SDL window and the GL context.
