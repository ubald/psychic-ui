Detailed Description

The platform side of a Window: a native window and its OpenGL context.

An implementation translates the platform's input and window events into calls on its Window and draws it with render(), with the window's GL context current.

Sizes: getWidth()/getHeight() are the window's size in the units the platform reports the mouse in, which is what the UI is laid out in. getFramebufferWidth()/getFramebufferHeight() are the size of what is drawn, in pixels: larger on a high pixel density display, by getPixelRatio().
