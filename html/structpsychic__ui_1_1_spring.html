Detailed Description

A damped spring pulling a value to its target: no duration, it settles when it gets there. Interrupted, it keeps its speed, so a value that reverses half-way turns smoothly. Below a damping of 2√(stiffness × mass) it overshoots and oscillates; at or above it, it doesn't.
