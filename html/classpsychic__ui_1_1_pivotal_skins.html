Detailed Description

Psychic UI's own look, the default set ("Default"): Pivotal's design system (P1 Faithful), with Pivotal Dark and Pivotal Light. A skin for every component, the bases for most, Pivotal's own for tabs, window controls and avatars, and the rules laying them out. Other sets fall back on it. 

window.skinSet<PivotalSkins>();
