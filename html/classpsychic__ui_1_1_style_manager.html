void psychic_ui::StyleManager::reset ( )

Forget the fonts, the skin set, the loaded stylesheets and every rule. The rules' styles are emptied but stay allocated, so a Style & obtained from style() stays valid: declaring the same selector again (usually by loading a stylesheet) brings that rule back.

◆ style()

Style & psychic_ui::StyleManager::style ( std::string selector)

Get the rule for a selector, declaring it if needed. Selectors are case insensitive. Rules apply like CSS: by specificity (weight), and on equal specificity the rule declared last wins.
