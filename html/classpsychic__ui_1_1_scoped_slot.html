Detailed Description

Owning slot handle: disconnects when destroyed or when another slot is assigned to it. Use it for a subscription you replace or drop, typically to a signal that outlives you: 

ScopedSlot _onMouseMove;
_onMouseMove = window()->mouseMoved.subscribe([this](...) { ... }); // disconnects the previous one first
