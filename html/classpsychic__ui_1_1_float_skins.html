Detailed Description

S5 Float, the sample skin set: rounded panels floating over a dotted canvas, gentle two-layer shadows, neutral greys and a violet accent, light first (Float Light, Float Dark).

It shows how little a skin set needs: it falls back on the default set for every skin and rule, and only overrides the rules whose look differs. Most of the change comes from its themes alone (corners, sizes, colors), since the default set's rules are written from the theme. 

window.skinSet<FloatSkins>();
