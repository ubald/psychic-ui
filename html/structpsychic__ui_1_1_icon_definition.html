Detailed Description

An icon: its elements on a square grid of grid units (16 for Pivotal's set, 24 for Lucide's), the whole grid filling the icon's box.

stroke is the width the source set strokes it with, in grid units, for reference: every icon is drawn with the same visual weight, the iconStrokeWidth style, so icons from both sets match side by side. Strokes have round caps and joins, as in both sets.
