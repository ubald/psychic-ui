Detailed Description

What a skin set and app stylesheets draw with: values only, so any theme works with any skin set. Read it with manager->theme() in StyleSheet::load (and the sizes of the current density with manager->sizes()); switching themes or densities replays the loaded stylesheets. Groups mix with designated initializers: Theme{.palette = themes::pivotalLight.palette}.
