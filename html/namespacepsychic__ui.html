Detailed Description

How a value moves to a new one: a duration along an easing curve, or a spring.

What an icon is made of, as data: the bundled sets are tables of these (generated by tools/icons/generate.py), and an application registers its own the same way (IconRegistry::add).

The types of the style properties: lengths, colors, enumerated values and interned strings. Each is checked when the call is compiled, so a typo or a wrong kind of value is a compile error.
