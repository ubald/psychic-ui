Detailed Description

template<class... T>
class psychic_ui::Slot< T >

Subscription to a signal, returned by Signal::subscribe.

The signal keeps its slots alive, so dropping the returned pointer does not disconnect: keep it in a ScopedSlot to disconnect later, or extend from Observer and use subscribeTo to disconnect when the observer dies.
