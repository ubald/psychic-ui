Detailed Description

The transition style property: which properties blend from their old value to their new one when it changes, and with what timing, like CSS's transition. A few timings, each for a set of properties: 

manager->style("Button")
    .transition({Property::backgroundColor, Property::borderColor}, Timing{100ms})
    .transition(Property::outlineColor, Timing{150ms, Ease::Out});

Like CSS's, it cascades as a whole: the rule that wins sets every transition of the div, the others' don't add to it. Only animatable properties (see PSYCHIC_UI_STYLE_PROPERTIES) blend; the others change at once.
