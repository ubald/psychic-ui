Detailed Description

A design system's implementation: a skin per component (registerSkins), the rules that lay them out (load, written from manager->theme()), and the theme it ships with. A set may implement only some skins: the others come from its fallback set, whose skins and rules are registered and loaded first. A style manager has one set at a time (StyleManager::skinSet<S>()).
