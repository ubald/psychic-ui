Detailed Description

Runs Psychic UI windows on SDL3: sets up SDL's video, gives each opened Window an SDL window with an OpenGL context, and runs the event loop until every window is closed. 

psychic_ui::SDL3Application app;
app.open(std::make_shared<MyWindow>());
app.run();

To put Psychic UI in an SDL window you create yourself, use SDL3SystemWindow directly.

◆ run()

void psychic_ui::SDL3Application::run ( )

Handles events and draws the windows, until none is visible or SDL asks to quit. A window is drawn after an event for it, and while it needs frames (Window::untilNextFrame: a style or layout change, an animation, a requested frame, a timer); when none does, the loop sleeps in SDL until an event or the soonest timer.
