Detailed Description

How a value moves to a new one: a duration along an easing curve, or a spring. The default timing, and a duration of 0, are instant. 

Timing{150ms}                 // CSS's default curve
Timing{100ms, Ease::Out}
Timing{Spring::Snappy}
